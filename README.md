## Codespaces Port Overview

| Port | Service | Type |
|------|---------|------|
| 1433 | MSSQL | Relational |
| 3306 | MySQL | Relational |
| 5432 | PostgreSQL | Relational |
| 6379 | Redis | In-memory |
| 27017 | MongoDB | Document |
| 8081 | Mongo Express | UI |
| 8082 | phpMyAdmin | UI |
| 8083 | Adminer | UI |
| 8084 | pgAdmin | UI |
| 8085 | RedisInsight | UI |

## Getting Started in Codespaces

1. Open the terminal and run `./start-databases.sh`
2. Go to the **Ports** tab and add the ports above manually
3. Add labels from the table above for easy reference
